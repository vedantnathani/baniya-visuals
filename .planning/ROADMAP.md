# Roadmap: Baniya Visuals Works Portfolio

## Phase 1: Project Initialization & Theme Engine
- Initialize Next.js project with TypeScript, Tailwind CSS, Motion, Lenis, Lucide/Phosphor icons
- Setup CSS variables for 3 switchable themes (Dark Cinema, Light Editorial, Bold Color)
- Setup typography (Cormorant Garamond, Plus Jakarta Sans, JetBrains Mono)
- Create film-grain texture and global Lenis smooth scrolling provider
- Setup unified config `src/data/config.ts` and project schema `src/data/projects.ts`

## Phase 2: Navigation & Hero Experience
- Preloader / Intro Curtain reveal with 0-100 counter and skip button
- Fixed header with wordmark, links, theme switch, Hire Me CTA, and mobile fullscreen menu
- Character-led Hero with word-by-word headline reveal
- 4-style interactive video switcher (Cinematic, Reels, YouTube, Shorts)
- Stats bar, CTAs, and scroll indicator

## Phase 3: Work Showcase & Services Accordion
- Interactive Selected Work list with category filters (All / Reels / Shorts / Cinematic / YouTube)
- 9:16 vertical video preview card (sticky on desktop, inline tap on mobile)
- Fullscreen video modal player with sound toggle
- Numbered Services accordion (01-07) with rich hover details

## Phase 4: Pricing, About & Creator Credentials
- 3-tier Pricing cards with gold styling and WhatsApp prefilled booking links
- About section with creator portrait, bio, "I edit stories, *not just footage.*" headline, pulsing status, CapCut/Alight Motion tools block, and creative strengths
- Scroll-driven Notes cards (Pacing, Music Sync, Tailored Edits)

## Phase 5: Floating Now Widget, Contact, Footer & Netlify Ready
- "NOW: Editing..." floating badge with dynamic project status
- Contact section with "LET'S WORK TOGETHER", direct channels, and working contact form
- Footer with social links, back-to-top, and copyright
- Custom magnetic cursor with "PLAY" hover state
- Complete SEO metadata, OpenGraph, JSON-LD, Netlify build verification
